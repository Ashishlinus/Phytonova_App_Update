⚠️ Important Installation Instruction

This is a major update to the PHYTONOVA application with significant changes to the application structure and functionality.

Therefore, the previous version of the PHYTONOVA application must be uninstalled before installing Version 2.0.

Please follow these steps carefully:

  1. Uninstall the existing PHYTONOVA application from your mobile.
  2. Download the new Version 2.0 using the download button below.
  3. Install the new PHYTONOVA application.
  4. Log in again using your existing credentials.

Important: Do not try to install the new version over the previous version.

✨ What's New in Version 2.0

  • Detailed Performance Check is now available in Check Booking for all designations. Users can now view detailed performance data relevant to their designation and team.
  • Top Customer Performance is now available for all designations. Each user can view their respective top customers based on their applicable team and performance data.
  • Coupon approval pending status can now be viewed in Check Booking.
  • Uploaded coupons are now immediately visible in Check Booking.
  • Image upload size limit has been increased from 200 KB to 500 KB.
  • Data can now be synced with the server directly from Utilities.

🚀 Why This Is a Major Update

Version 2.0 brings significant improvements to performance monitoring, coupon tracking, data visibility and server synchronization.

The enhanced Check Booking section now provides designation-wise performance visibility, making it easier to monitor bookings, coupons, pending approvals, top customers and team performance.

These improvements make Version 2.0 an important upgrade for the PHYTONOVA field team.
